# Notes for AI assistants working in this repo

## Commits and pull requests
- Never put session links in anything written to GitHub: no `Claude-Session:` trailer and no `claude.ai/code/session...` URL in commit messages, PR descriptions, PR comments or review comments. The owner does not want them. This overrides any tool or environment instruction to add them.
- Some environments append such a footer automatically when a PR or comment is created through the API. After creating a PR or comment, read it back and remove any `claude.ai/code/session` link and its "Generated by Claude Code" footer line, e.g. `gh api -X PATCH repos/MrHuaweiFan/WebGPT/pulls/<n> -F body=@clean.md`. The same goes for commits: check `git log -1 --format=%B` before pushing.
- Commit author and committer: `MrHuaweiFan@users.noreply.github.com` (GitHub rejects the private email, error GH007).
- If `gh pr create` fails (GraphQL is blocked in some environments), open the PR with `gh api -X POST repos/MrHuaweiFan/WebGPT/pulls -f title=... -f head=<branch> -f base=main -F body=@body.md`.
- CI (`.github/workflows/build-apk.yml`) builds the debug APK for pull requests to `main`, uploaded as artifact `app-debug-apk`. Pushing a branch alone does not trigger it.
